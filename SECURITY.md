# Security Policy

Dustnado deletes files, so safety bugs matter.

If you find a case where Dustnado deletes something it should not (or could be tricked into doing so), please **do not** open a public issue first.
Use GitHub's **"Report a vulnerability"** (Security tab) on this repository, or contact the maintainer, Zeel Patel, through the e-mail on the GitHub profile.

Please include your Windows version, the command-line options used, and the relevant part of the report text file.
